 THE ENGINE UNDER THE STORY

Wayfinder.

A headless JavaScript library for parser fiction. Compiled grammar productions, scoped noun resolution, and a world that remembers.

No dependenciesOne script tagAny frontend
<script src="wayfinder.js"></script>

const story = new Wayfinder.Engine({
  id: 'my-story',
  objects: [
    {id: 'room', name: 'A room', room: true},
    {id: 'player', name: 'you',
      actor: true, parent: 'room'}
  ]
});

const result = story.execute('look');
